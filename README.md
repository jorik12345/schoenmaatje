# Schoenmaatje

Ruilplatform voor mensen met één voet of één been: bied de schoen aan die je niet draagt en vind iemand met dezelfde maat die precies die kant nodig heeft.

## Ontwikkelen

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # productiebuild in dist/
```

Gebouwd met [Astro](https://astro.build), [Supabase](https://supabase.com) en gehost op Netlify. Zonder Supabase-sleutels draait de site op voorbeelddata; zie [docs/supabase.md](docs/supabase.md) om de database in te richten.
